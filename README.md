# jupyterlab_practice

This repository was created as part of Module 7 of the UBC MDS Data Science Toolbox course, practicing advanced JupyterLab features: cell types, Markdown formatting, notebook views, shell commands, magic commands, and more.

## Contents

- question11.ipynb - Markdown headings and a Python function with LaTeX documentation
- question12.ipynb - shell commands, the timeit magic command, and HTML export
- question12.html - HTML export of question12.ipynb, without input code cells
- images/ - screenshots demonstrating completed exercises
- environment.yaml - Conda environment specification
- LICENSE - project license
- .gitignore - excludes log files, .DS_Store, and Jupyter checkpoint files
